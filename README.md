# Rydhampreet Kaur — Portfolio

A responsive static portfolio website using HTML, CSS and JavaScript.

## Preview
Open `index.html` in your browser. Internet is needed to load the optional Google Fonts; fallback fonts are included.

## Publish on GitHub Pages
1. Sign in to https://github.com/Rydham-nait
2. Create a **public** repository named `Rydham-nait.github.io` (exact spelling).
3. Upload `index.html`, `styles.css`, and `script.js` into the repository root, then commit.
4. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub publishes the site, the URL should be `https://Rydham-nait.github.io/`.

## Before publishing
- Review every project description for accuracy.
- Replace GitHub profile links with specific repository links once those repositories are public.
- Add a real professional email if you want a direct contact method (the site currently does not expose personal contact details).
- Add screenshots and your own branding logo if available.
- Check the Figma project sharing settings if you want visitors to view it.
